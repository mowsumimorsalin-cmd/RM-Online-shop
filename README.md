# Free E-commerce Website — Starter

This is the first storefront foundation for a GitHub Pages based store.

## Current features
- Responsive homepage
- Header/search/navigation
- Categories
- Offers section
- Product cards
- Discount pricing
- Product detail modal
- Add to cart / Buy Now
- Cart stored in browser
- Sort and search
- About / contact / policy placeholders
- Mobile-friendly layout

## Important
This is the storefront foundation, not yet a production order backend.

Next stages:
1. Replace placeholder brand/logo/products.
2. Build a real order form.
3. Connect orders to a free storage/notification method.
4. Add an admin-friendly editing system.
5. Add real product images, categories, policies and delivery details.
6. Test everything on GitHub Pages.
7. Later connect a custom .com domain without rebuilding the storefront.
